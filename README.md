Command Line Weather App
A simple and interactive Weather Application built using Node.js that allows users to check real-time weather information directly from the command line.

 Features:-
 Get weather information for any city.
 Display current temperature.
 Show weather conditions.
 Display additional weather details (if supported).
 Fast and easy command-line interface.
 Simple city-based weather search.
 Technologies Used
Node.js – JavaScript runtime environment.
JavaScript – Application logic.
Weather API – Fetching weather information.
NPM – Package management.
